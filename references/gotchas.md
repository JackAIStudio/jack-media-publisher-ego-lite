# 踩坑与实战退路（Ego Lite 版）

汇总四个创作者后台的真实暗坑与 Ego Lite 操作边界，按“会不会让你白干或传错稿”排序。每条均来自真实后台实测（2026-09 至 2026-11-19）。

---

## 一、B 站登录会话「假在线」导致封面白做

**现象**：进入 B 站投稿页 `member.bilibili.com/platform/upload/video/frame` 后页面可正常加载，甚至能传视频、打开封面编辑器并填好 4:3 和 16:9 双图，但在点击封面「完成」或「存草稿」时静默失败或无法保存。追查 `api.bilibili.com/x/web-interface/nav` 才发现返回 `code=-101`、`isLogin=false`（会话已过期）。

**修法**：在刚打开 B 站页面时、投递大文件或制作封面**之前**，优先核对账号昵称/头像真实可见，并通过 `page.fetch("https://api.bilibili.com/x/web-interface/nav", { credentials: "include" })` 确认 `data.isLogin === true`（注意：在 `member.bilibili.com` 调跨子域 `api.bilibili.com` 时**必须传 `{ credentials: "include" }`**，否则默认不带 Cookie 会把已登录态误报成 `-101`）。若未登录或会话过期，立即 `await task.handOff()` 交给 Jack 扫码登录后再继续。

## 二、微信视频号在上传期间全表单锁定，且后台标签页读不出视频时长

| 平台 | 上传/处理期间表单可编辑？ |
|---|---|
| 小红书 | ✅ 标题 / 话题 / 声明 / 封面 可预填 |
| 抖音 | ✅ 标题 / 声明 可预填 |
| B站 | ✅ 标题 / 标签 / 分区 / 声明 可预填 |
| **微信视频号** | ❌ **锁定**：「文件上传中，请等待完成后再编辑」 |

**两大实测坑**：
1. **必须等上传与转码全部完成、字段解锁后**，才能填写视频描述、话题、位置、原创和封面。
2. 当视频号编辑页长期处于非当前激活标签（`document.visibilityState === 'hidden'`）时，页面内视频元素可能维持 `readyState === 0` 且 `duration` 为空/`NaN`，卡在「本地待读取」。需短切激活一次该页（`page.evaluate` 不可靠唤醒时切到前台观察），读出与 `ffprobe` 一致的时长和分辨率后再等平台处理回执。
3. **操作期静音、交接前还原**：视频号（及小红书、抖音）上传/复开后可能自动有声播放视频预览，打扰作者。进页及每次恢复/复开后，应立即遍历主文档及 `wujie-app` shadow root 将 `<video>` 和 `<audio>` 设成 `muted = true` 并调用 `pause()`，**切勿把 `volume` 改为 `0`**；全部验收完毕、准备 `finish({ keep })` 交接给用户前，保持媒体暂停（监听或防止意外自动播放）并把 `muted` 还原为 `false`，以免用户接手后手动点预览却听不到声音。
4. **横屏设第二张封面弹「使用此素材作为封面？」**：视频号横屏稿设好个人主页 3:4 封面后，点击分享卡片 4:3「编辑」可能先浮出「使用此素材作为封面？」提示，**必须点「直接编辑」真正进入分享卡片弹窗后再传 4:3 图**，否则文件选不进目标卡。

## 三、B 站封面的双面板与同步陷阱

B 站封面编辑器包含 **#editor_4_3（首页推荐）** 和 **#editor_16_9（个人空间）** 两个独立面板，常见三个坑：
1. **进入弹窗干扰**：新版封面编辑器有时先弹出「智能生成封面」引导，需先点「不使用」才能手动传图。
2. **未切对面板导致覆盖错槽**：`active` 类在 `#editor_4_3` / `#editor_16_9` 的**父元素**上，不在自己身上，且不能用 `/active/.test(...)`（会误中 `inactive`）。上传前必须按空格切分父元素 `className` token 验证 `active`！
3. **保存时弹窗提议同步**：点「完成」可能弹出「检测到个人空间封面（16:9）未修改。是否将「4:3封面」的改动同步到「16:9封面」？」。**必须选「不同步，手动编辑」**，点同步会把 4:3 覆盖到 16:9 槽位上。

## 四、B 站「仅话题」词在标签框静默消失 & 自动塞无关标签

1. **自动无关标签占坑 & SVG 不可直接 `.click()`**：平台会根据文件名或内容自动往标签栏里塞默认词（如「记录」「原创」）。必须在加标签前先清理无关标签；注意 `<svg>` 元素没有 DOM `.click()` 方法（直接调会抛 `TypeError`），应先 `scrollIntoView` 再用 `page.mouse.click` 点击关闭图标坐标。**切勿在空输入框里按 Backspace**，B 站会删掉最后一个已保存的标签！
2. **「仅话题」词静默吞掉**：有些词在 B 站只以「话题」形态存在，直接在标签框回车会被静默清空且无任何提示。改走界面上的**「参与话题 → 搜索更多话题 → 精确点选 → 确定」**，选完后回读 `.label-item-v2-content`。若该词连话题也搜不到且是用户指定原词，保留作明确待办报给 Jack，**绝不悄悄换词**。
3. **未抽帧前的封面空槽**：视频刚上传尚未生成默认抽帧图时，`.cover-content` 里还没有「更改封面」文字按钮，而是空槽 `.cover-empty-pill` / `.cover-slot`，直接点它即可打开双封面编辑器。
4. **内部滚动容器与创作声明收起误触**：B 站投稿页有内部滚动容器，操作分区、标签、声明或存草稿前先 `scrollIntoView({ block: 'center' })`；选创作声明时直接 DOM 精准点击目标 `.bcc-option`，防止收起下拉时误切到「含虚构演绎内容」。

## 五、隐藏的 `<input type="file">` 与动态文件选择器

四个平台的文件输入框大都是隐藏的（`0×0` / `opacity: 0` / `display: none`）：
- 在 Ego Lite 中，若页面已有稳定的 `<input type="file">`（如小红书 `input.upload-input` 或视频卡片内部），`page.setInputFiles()` 可直接设置，但必须核对命中了当前视频/当前封面卡片对应框（例如 B 站页内同时有字幕 `.txt` 框和旧版 `1×1` 框，不能盲选）。
- 若页面通过点击投放区动态触发选择器或存在多重嵌套，必须**先**建立 `const chooserPromise = page.waitForFileChooser({ timeout: 10_000 })`，**再**点击可见投放区 `ref`，然后 `await chooser.setFiles(absPath)`。注意切勿先点击后等待，否则事件已错过会超时卡死。

## 六、微信视频号「保存草稿」不保存视频标注 & `wujie` Shadow DOM

1. **草稿丢标注**：实测点击视频号「保存草稿」并从草稿箱复开同一条稿时，短标题与描述在，但「视频标注」必定回退到占位符「选择视频标注」。因此必须走：**先保存草稿 → 另开标签进草稿箱复核 → 回到原编辑页最后设置「视频标注」→ 读回按钮确认后不再点保存、直接留页交接**。
2. **`wujie-app` shadow root 与隐藏弹窗陷阱**：视频号发布表单嵌套在 `wujie-app` 的 shadow DOM 里，直接在顶级 `document` 运行 `querySelector` 往往只能读到外层导航栏。写 `page.evaluate()` 探测字段或 `File` realm 时需先进入 `document.querySelector('wujie-app')?.shadowRoot`。此外，页内常驻隐藏的 `.weui-desktop-dialog`（如「将此次编辑保留?」和隐藏「确定」按钮）：声明原创必须只取 `getBoundingClientRect().height > 80` 的可见弹窗；封面弹窗确认必须**严格匹配文本等于 `"确认"` 的可见橙色主按钮**（不可写成 `=== "确认" || === "确定"`）。
3. **草稿箱直达路径与前台渲染**：草稿箱真实路径为 `https://channels.weixin.qq.com/platform/post/draftListManager`（不是 `/platform/post/draft`）；新开临时页查草稿箱前须 `bringToFront` 并用 `waitForFunction` 等 `wujie-app` 渲染出目标条目。
4. **位置设「不显示位置」**：点击 `.post-position-wrap .location-name` 打开列表后，用 `page.click('text="不显示位置"')` 穿透 shadow DOM 直接选定最稳，随后回读 `.post-position-wrap` 确认不再显示城市名。

## 七、小红书话题面板竞态、悬浮发布条遮挡、定时开关误触与大视频退路

1. **悬浮发布条 `<xhs-publish-btn>` 遮挡与正文未聚焦**：小红书底部悬浮的 `<xhs-publish-btn>` 常拦截 `div.tiptap.ProseMirror` 中下部点击；且填完标题不先聚焦正文就直接点「话题」，会把话题敲进标题框撑超 `20` 字。应先将 `ProseMirror` 滚到视口中央、点击其上部坐标聚焦后再点 `button.contentBtn.topic-btn`。
2. **原创开关误触定时发布**：`.custom-switch-card .d-switch` 同时匹配「原创声明」与「定时发布」两个开关，**必须限定 `.original-wrapper .d-switch`**，避免意外打开定时发布。
3. **话题建议面板竞态**：面板返回有延迟且会异步重渲染。若先读取旧位置再点，很容易错点成同前缀词。每次输入关键词等待面板就绪后，必须**重新运行 `page.snapshot()` 获取最新 `ref` 或在 `.tippy-box .item` 匹配精确名称后点击**，随后在 `div.tiptap.ProseMirror a.tiptap-topic` 核对名称。
4. **横封面进编辑器默认仍选 3:4 裁剪框**：上传 4:3 横封面到小红书「设置封面」弹窗时，弹窗默认仍选中左侧「3:4」裁剪比例。**必须点击左侧「裁剪 → 4:3」切换为横版比例框并目视确认未裁掉两侧文字，再点「完成」**。
5. **大视频封面编辑器报错**：遇到「视频加载遇到问题」时，直接点击页面官方退路**「回退到旧版封面编辑弹窗」**，然后上传相应方向封面并确认。
6. **「内容类型声明」没有“无需声明”选项**：当成片不含 AI 生成素材也无其他需声明项时，**留空不选**（保持占位符「添加内容类型声明」）即代表无需声明。
7. **本地草稿上限**：小红书视频笔记草稿存储在**当前浏览器本地**（上限约 100 条），同一浏览器同一账号内可见；已满时不可擅自删除旧稿，需请 Jack 决策。

## 八、抖音动态 `ref`、弹窗拦截、切封面弹窗与「继续编辑」单入口覆盖风险

1. **`#添加话题` 按钮 `ref` 会漂移**：每添加一个话题后组件会重绘，下一轮必须重新快照获取新的 `ref` 或使用 `text="#添加话题"`，避免词条被当成普通文本写入而不变成 `[data-mention="#"]` 实体。
2. **双封面弹窗指针拦截**：不要误向页面外层的隐藏 input 传图；先将 `.cover-Jg3T4p` 滚到视口中央并稍等后点击打开双封面弹窗，在弹窗内切换「设置竖封面」/「设置横封面」遇到「使用此素材作为封面？」点「直接编辑」，然后直接对黑色上传块 `.upload-tips-KomyJM`（或拖拽区）挂 `waitForFileChooser` 并用 `mouse.click` 点击，避开 `dialog intercepts pointer events`。
3. **「继续编辑」风险**：抖音上传页仅弹出最近一次未发布视频的「是否继续编辑？」。复开前或点击后，必须立刻核对**标题与播放器时长**，确认是本条才操作；若发现已有别人的未发布草稿，先保留并报告 Jack，切勿覆盖。

## 九、Ego Lite 多会话与跨重启 `spaceId` 漂移

1. **`spaceId` 并非永久固定**：Ego Lite 重启或空间重整后，原有空间的数字 ID 可能变化（实测曾出现进度文件记 `spaceId: 9`，重启后对应空间变为 `id: 4`）。续做时必须用 `listTaskSpaces()` 按 `spaceId` **结合 `name` / `taskId`** 双重核对，并在各平台页面核对标题、片长和保存时间。
2. **禁止擅自接管 `user` 空间**：按 `ego-browser` 指南，检测到 `ownership: "user"` 的已有同名空间时，须先经用户同意才可 `claimTaskSpace(id)`。
3. **交接清理页签**：草稿复核常会多开草稿箱列表页、视频预览页等中间页签。交接前核对 `await task.tabs()`，只把每平台最终编辑页的 `label` 传入 `await task.finish({ keep: handoffLabels })`，其余中间页不要保留。
