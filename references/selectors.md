# Ego Lite 页面控件

用 `ego-browser skill` 取得本机 API 用法。每次切换编辑页、封面卡或弹窗后，重新观察当前页。控件名称和标签页编号取自当前任务空间。以下定位依据来自 2026-11-18 的网页实测。

## 文件与标题

| 平台 | 对应的表单区域 |
|---|---|
| 小红书 | 「上传视频」卡内的文件框通常接受 `.mp4` 和 `.mov`。上传后在「填写标题」框回读标题。 |
| 抖音 | 「点击上传」区域内选择接受视频的文件框。在「作品标题」框回读标题，并观察编辑页的上传结果。 |
| B 站 | 投稿页 `.bcc-upload-wrapper` 内接受 `.mp4` 的视频文件框。标题框的占位符含「稿件标题」。同页还有字幕和封面各自的文件框。 |
| 微信视频号 | 在 `wujie-app` 的表单中定位视频上传卡。描述编辑器为 `.input-editor`，短标题有独立输入框。先核对平台上传处理状态，再填写字段。 |

有现成的文件框时用 `page.setInputFiles` 传入绝对路径。仅在点击后才创建文件选择器的控件，先取得 `page.waitForFileChooser()` 的 Promise，点击当前上传入口，再用返回的选择器指定文件。读回的文件名及字节数证明已选文件，平台回执证明已接收。

## 话题

- 小红书点击「话题」，输入查询词，选中候选中完整匹配的一行。在正文编辑器的 `.tiptap-topic` 中核对已落地的话题。同名候选优先借当前行的实体信息辨认。
- 抖音点击「#添加话题」，从当前候选选中具体实体。每次提交后核对正文内的 `[data-mention]`，移出已选实体再输入下一个词。
- B 站在标签框逐个输入并按 Enter，回读 `.label-item-v2-content`。移除与本条无关的自动标签时，点对应标签自己的关闭控件。
- 微信视频号在视频描述中输入 `#话题`，从同一编辑器的 `.hl.topic` 核对平台识别到的名称。

## B站封面

在目标草稿的「添加封面」或已有封面卡打开编辑器。按「首页推荐封面（4:3）」与「个人空间封面（16:9）」分别定位上传区；两槽均为空时可以直接在各自的空卡选图。分别使用不同构图时，先核对「双比例同步改动」状态，再向对应卡片选择源图。点封面编辑器的「完成」，检查主卡图片。

存稿并复开同一 `draftId` 后，首页图对应 `extra`，空间图对应 `main`。已编辑的图片资源有时从 `edited` 转入 `origin`。以复开的实际图片和相应源图比对构图和比例。

## 抖音封面

在目标稿的竖封面卡打开编辑器，查看「竖封面预览（3:4）」。在当前编辑区选图，再切到「设置横封面」，确认预览比例为 4:3 后选横图。「完成」返回编辑页后核对两张主卡。点「暂存离开」，从「继续编辑」复开本稿，逐张比对卡片内已加载的图片。

## 视频号标注

在正常可编辑的表单中核对「声明原创」「位置」和「视频标注」各自的值。取内容类型的最终显示值时，先收起候选菜单。保存和复查草稿后，把末次选好标注的原编辑页交给作者。[草稿复查与交接](<verification.md#草稿复查与交接>)
