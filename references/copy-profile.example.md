# 分发伴生文案个人配置范例（Copy Profile Example）

本文件是开源仓库自带的空白配置模板，用于定制发布草稿交接时自动附带的伴生分发文案（如微信朋友圈转发配文、X 推文正文、YouTube 标题与简介）。

## 启用方式

`/local/` 目录已被本仓库 `.gitignore` 忽略，**永远不会被提交到公开 Git 仓库**。按需二选一启用：

1. 直接复制本文件为 `local/copy-profile.md` 并填入你自己的语境与范例；
2. 将你的私有仓库或笔记目录中的个人文案配置文件软链接到 `local/copy-profile.md`：

```sh
ln -s /path/to/your-private-repo/copy-profile.md \
      ~/.agents/skills/jack-media-publisher-ego-lite/local/copy-profile.md
```

3. （可选）如果你还整理了自己的历史朋友圈/推文纯文本语料（如 `style_corpus.md` / `moments.jsonl`），也可以一并软链接到 `local/moments/`（同样被 `.gitignore` 忽略）。助手平时只读精简的 `copy-profile.md`，遇到特殊题材时按需检索 2–3 条同类历史原话对齐语气：

```sh
ln -s /path/to/your-private-repo/moments \
      ~/.agents/skills/jack-media-publisher-ego-lite/local/moments
```

若 `local/copy-profile.md` 不存在，助手在交接时仍会自动提供简洁、克制的通用伴生文案初稿。

---

## 1. 通用语感与红线

- 篇幅：默认 2–4 行短句，说人话、直接给事实，避免营销号腔与夸张形容词。
- 外链习惯：微信朋友圈与 X 均可直接附项目或个人站链接，按个人习惯决定直接放文末还是放评论区。
- 避坑：禁止自动代填进 X 撰写页（除非作者明确要求回填），更禁止代点任何发布按钮。

## 2. 常用公开链接（按需填写）

- 个人主页：`https://example.com`
- 常用开源仓库或项目页：`https://github.com/<your-org>/<your-repo>`

## 3. 分渠道写作规则

### 微信朋友圈（转发视频号 / 直发视频）

- **读者定位**：熟人、客户、非技术背景朋友。
- **写法**：少讲技术细节，直接说清这条视频展示了什么结果或解决了什么日常麻烦，可结合一句真实生活片段，按需附外链。
- **个人范例**：

```text
（粘贴 1–2 条你平时最满意的朋友圈真实发文，助手会直接对齐你的语气与节奏。）
```

### X（Media Studio 撰写页「有什么新鲜事?」）

- **读者定位**：技术同行、开发者、产品或行业社区。
- **写法**：讲工具选型、实现思路、真实踩坑或对上游开源项目的致谢（需要 `@` 的账号可在开工对齐时说明），按需直接附仓库链接；面向海外时可附极简英文备选。
- **个人范例**：

```text
（粘贴 1–2 条你平时最满意的 X 真实推文，助手会直接对齐你的语气与长度。）
```

### YouTube（可选 / 预留槽位）

- **读者定位**：搜索与长尾观众。
- **交付项**（仅当本次涉及 YouTube 或明确要求时输出）：可检索标题 + 2–3 句简洁说明 + 关键链接 + 必要时间轴。
